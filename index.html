PartStack
Inventaire intelligent de pièces détachées.
Configuration unique — 5 min.
1
Crée un projet Firebase (gratuit)
Va sur console.firebase.google.com → Nouveau projet → donne-lui un nom (ex: partstack).
2
Active Firestore
Dans ton projet → Build → Firestore Database → Créer une base de données → Mode test → Sélectionner une région (europe-west1) → Activer.
3
Récupère ta config
⚙️ Paramètres du projet → Tes applications → Ajouter une app (icône </>) → Enregistre-la → copie le contenu de firebaseConfig.
4
Colle ta config ci-dessous
Colle le JSON entre accolades (ou le bloc entier const firebaseConfig = …).

Ta config est stockée uniquement sur ton appareil.
Elle ne quitte jamais ce téléphone.
